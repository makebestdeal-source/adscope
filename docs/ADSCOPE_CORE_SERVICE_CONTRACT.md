# AdScope Core Service Contract

AdScope의 핵심은 메뉴가 아니라 데이터 계약이다. 모든 메뉴는 아래 원소스를 같은 규칙으로 정제해서 각 화면 양식에 맞게 보여줘야 한다.

## Core Flow

1. 명확한 산업 카테고리
2. 제품/서비스 구분
3. 정제된 광고주
4. 매체비 산출
5. 광고 효과/성과 평가
6. 이미지 소재와 텍스트/키워드 광고 소재
7. 소셜 채널 수집
8. 소셜 콘텐츠 수집
9. 소셜 인게이지먼트 수집
10. 소셜 이미지/썸네일/URL 수집
11. 광고 URL과 공식 사이트 URL 수집
12. 보고서/다운로드 메뉴에서 다운로드 일원화

## Non-Negotiable Rules

- 메뉴별로 광고주명, 광고비, 이미지 URL, 제품/서비스명을 따로 계산하지 않는다.
- 메뉴는 원소스를 원하는 형태로 보여주는 프레젠테이션이어야 한다.
- 광고주가 라이브러리 ID, 사람 이름, 광고 문구, 외국어 광고 카피로 보이면 실패로 본다.
- 단일 저신뢰 역산값을 정확한 원 단위 광고비처럼 노출하지 않는다.
- 이미지형 광고는 이미지 경로 또는 R2 URL까지 검증되어야 한다.
- 검색광고 소재는 이미지가 없어도 텍스트/키워드 소재로 정상 표시되어야 한다.
- 네이버/구글 등 복수 채널 선택은 교집합이 아니라 합집합으로 조회해야 한다.
- 소셜 콘텐츠는 썸네일, 원문 URL, 업로드/수집일, 조회/좋아요/댓글 중 최소 하나의 반응 지표를 함께 갖춰야 한다.
- 공식 사이트 URL은 광고주 마스터의 정제 필드로 관리하고, 광고 URL은 광고 상세의 원본/랜딩 필드로 유지한다.
- 보고서/PDF/XLSX/PPT 다운로드는 개별 메뉴에 흩뿌리지 않고 보고서&다운로드 메뉴에서 관리한다.

## Validation Gate

수집, 필터, 머지, 업로드, 배포 전에는 아래 스크립트를 먼저 실행한다.

```powershell
python scripts\core_flow_gate.py --days 30
```

이 게이트는 다음 항목을 확인한다.

- 업종 마스터 수
- 제품/서비스 카테고리 수
- 최근 광고 중 업종/제품/광고주 연결 광고 수
- 제품/서비스 누락률
- 라이브러리 ID/플레이스홀더형 광고주 비율
- 광고 URL 커버리지
- 공식 사이트 URL 커버리지
- 캠페인 광고비 커버리지
- 캠페인 효과 커버리지
- 이미지 소재 경로 커버리지
- 키워드 텍스트 광고 커버리지
- 소셜 채널 수집량
- 소셜 콘텐츠 수집량
- 소셜 URL/썸네일/인게이지먼트 커버리지

현재 `merged_db.db` 기준으로 확인된 주요 실패 항목:

- 제품/서비스 분류 누락률: 94.67%
- 캠페인 효과 커버리지: 0.06%

따라서 다음 개선 우선순위는 화면 장식이 아니라 제품/서비스 분류 백필과 캠페인 효과 산정 파이프라인 복구다.

## Menu Mapping

- 산업별 현황: 산업 카테고리 기준으로 광고주, 제품/서비스, 광고비, 이미지/소재 요약을 보여준다.
- 제품/서비스: 제품/서비스 카테고리 기준으로 광고주, 광고 수, 매체비, 소재를 보여준다.
- 광고주 상세: 정제 광고주 기준으로 공식 URL, 광고 URL, 제품/서비스, 캠페인, 매체비, 이미지/키워드 소재, 소셜 콘텐츠를 보여준다.
- 광고소재 이미지: 이미지형 광고 소재만 보여준다.
- 광고소재 키워드: 네이버/구글 검색광고 텍스트/키워드 소재를 보여준다.
- 소셜 인사이트: 소셜 채널, 콘텐츠, 썸네일, URL, 인게이지먼트, 효과 지표를 보여준다.
- 캠페인 효과: 충분한 사전/사후 데이터가 있는 캠페인만 효과를 수치화하고, 근거가 부족하면 `-` 또는 데이터 부족으로 표시한다.
- 보고서&다운로드: XLSX/PDF/PPT/ZIP 등 다운로드를 일원화한다.
